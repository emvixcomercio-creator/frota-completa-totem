# Frota Completa

Jogo de totem da **Sem Parar Empresas**: os produtos caem e a Fiorino apara.
A **tag é dourada** — quem pega a tag recolhe, de uma vez, tudo que estiver
caindo na tela, porque uma tag resolve todas as frentes da frota.

Alvo: TV touch de 55" em pé, 1080x1920. Roda no navegador, sem instalar nada.

Companheiro do [Rota da Frota](https://emvixcomercio-creator.github.io/rota-da-frota-totem/),
a outra ideia da mesma ativação.
